Private Chat

Encrypted text and file sharing for a small private group.

The room code and the passphrase are two different secrets. The room code says which conversation to load; the passphrase is what actually encrypts and decrypts the messages and files, so give both, separately, to people you trust — ideally not in the same message. Everyone must enter the exact same passphrase or they will only see "unable to decrypt". There is no password recovery: if the passphrase is lost, that room's history is unreadable. Files are limited to about 12 MB each. Voice calls are experimental, work one on one, and may fail on strict corporate or campus networks because there is no relay server behind them.
